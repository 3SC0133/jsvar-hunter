# Security Policy

## Supported Versions

Security fixes are currently provided for the latest version available in the `main` branch.

## Reporting a Vulnerability

If you discover a security vulnerability in JSVar Hunter itself, please report it privately rather than opening a public issue.

When reporting a vulnerability, include:

- A clear description of the issue
- Affected file or component
- Steps to reproduce
- Proof of concept, when applicable
- Potential security impact
- Suggested remediation, if available

Please avoid including sensitive information in public issues.

## Responsible Disclosure

Please allow reasonable time for investigation and remediation before publicly disclosing a vulnerability.

## Scope

This policy applies to vulnerabilities in the JSVar Hunter project itself.

It does not provide authorization to scan or test third-party systems.

When using JSVar Hunter against external targets, you are responsible for ensuring that the target is explicitly authorized and within the applicable testing scope.
