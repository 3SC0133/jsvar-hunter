# Changelog

All notable changes to JSVar Hunter are documented here.

## [2.0.0] - Initial Public Release

### Added

- JavaScript resource discovery
- Homepage JavaScript extraction
- Passive historical URL discovery
- In-scope JavaScript filtering
- HTTP accessibility validation
- Redirect tracking
- API endpoint discovery
- GraphQL indicator detection
- WebSocket URL detection
- Absolute URL extraction
- HTTP client call detection
- Source map detection
- Potential token and credential candidate detection
- Console/debug statement detection
- TXT reporting
- JSONL output
- Configurable HTTP timeout
- Optional TLS certificate verification bypass
- Verbose execution mode
- CLI help and version information

### Notes

JSVar Hunter is designed for reconnaissance and JavaScript attack-surface discovery.

Detected artifacts require manual validation and do not automatically represent confirmed vulnerabilities.
